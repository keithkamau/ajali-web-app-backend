# Ajali! Backend API

Emergency Incident Reporting System - Django REST API

## Tech Stack

- Django 4.2.7
- Django REST Framework 3.14.0
- PostgreSQL
- JWT Authentication
- Cloudinary for file uploads

## Setup Instructions

### Prerequisites

- Python 3.10+
- PostgreSQL 14+
- pip

### Installation

1. Clone the repository

```bash
git clone <repository-url>
cd ajali-backend
```
